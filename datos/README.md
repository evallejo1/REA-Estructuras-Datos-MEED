# Generador de datos y servidor local de desarrollo

Este directorio contiene ejemplos de datos en diferentes formatos para ser cargados en la aplicación interactiva de Estructuras de Datos y Algoritmos:

1. `datos_numeros.csv`: Lista de valores numéricos de prueba con diferentes distribuciones.
2. `datos_valores.txt`: Secuencia de números enteros para pruebas rápidas de ordenamiento y búsqueda.
3. `datos_estudiantes.json`: Conjunto de datos estructurados con identificadores y calificaciones.
